# 檔案總管顯示 DWG 版本欄位

本工具可在 Windows 檔案總管顯示「DWG 版本」與「DWG 格式代碼」，方便查看及排序圖檔。
不需要安裝 AutoCAD，適用 Windows 10／11 的 x64 電腦。

## 下載

**[下載 DwgVersionColumn.zip](https://github.com/kv1012tiger/DwgVersionColumn/releases/latest/download/DwgVersionColumn.zip)**

[下載頁面](https://github.com/kv1012tiger/DwgVersionColumn/releases/latest)

目前為 v1.0.1 圖形安裝版。請選擇 `DwgVersionColumn.zip`，GitHub 自動附加的 Source code 壓縮檔不是安裝包。

## 安裝方式說明

1. 完整解壓縮 ZIP。
2. 開啟 `DwgVersionColumnSetup.exe`。
3. 按「安裝／更新」，並允許 Windows 系統管理員權限提示。
4. 完成後先儲存工作，再登出並登入 Windows，或重新啟動電腦。
5. 檔案總管切換「詳細資料」，在欄位標題按右鍵 →「其他…／更多…」。
6. 勾選「DWG 版本」或「DWG 格式代碼」，按「確定」。

## 注意事項

- 「DWG 版本」表示檔案儲存格式，不一定是建立圖檔的 AutoCAD 年份。本工具只能查看版本，不能轉換格式。
- 解除安裝：開啟同一個 `DwgVersionColumnSetup.exe`，按「解除安裝」。
- 請保留安裝程式供之後更新或解除安裝使用。
